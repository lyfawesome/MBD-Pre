# motor.STEP 部件 75/76 镜像等价案例

记录日期：2026-09-07

状态：已诊断，暂不修改算法。

## 问题

快速候选层把部件 75 和 76 归为同一候选组，但当前 `rigid` 精确层无法找到只包含正旋转和平移的完整拓扑对应，因此最终将两者拆开。需要判断它们究竟是手性差异、B-Rep 表达差异，还是刚体匹配器漏检。

## 结论

部件 75/76 是精确镜像件：

- 在只允许正旋转和平移的 `SE(3)` 等价关系下不同；
- 在允许反射的 `O(3)` 等价关系下相同；
- 没有证据表明本次失败来自 B-Rep 拆边/拆面差异；
- 搜索没有触及组合上限，基本排除当前刚体匹配器漏检。

更准确的关系标签应为：

```text
different_under_SE3
same_under_O3
mirror_equivalent
```

当前代码尚未增加这些状态，冻结报告仍保留原始的 `alignment_failed`。

## 证据

快速描述符对比：

| 指标 | 结果 |
| --- | --- |
| 综合距离 | `6.16382339113275e-15` |
| 相似度 | `0.9999999999999938` |
| 拓扑距离 | `0.0` |
| 几何距离 | `2.4598471831723967e-14` |
| 形状距离 | `5.767955557622884e-17` |
| 尺寸距离 | `1.7796813910082876e-17` |

两个实体的体积、表面积、总边长、惯性量和包围盒尺度在浮点误差内一致，且都包含 23 个面、48 条边和 32 个顶点。

正旋转测试在三个约束等级均失败：

```text
仅顶点集合                  -> 无正旋转对应
顶点 + 类型化边            -> 无正旋转对应
顶点 + 类型化边 + 面边界   -> 无正旋转对应
```

刚体搜索诊断：

| 指标 | 结果 |
| --- | ---: |
| 每个顶点距离指纹最大重复次数 | 1 |
| 三个锚点各自候选数 | 1、1、1 |
| 满足锚点距离的候选三元组 | 1 |
| 搜索上限 | 10000 |
| 是否触及搜索上限 | 否 |

每个顶点的距离指纹都是唯一的，因此距离保持映射也是唯一的。该唯一映射需要行列式为 `-1` 的反射，而不是行列式为 `+1` 的正旋转。

对部件 75 施加关于 `x=0`（YZ 平面）的反射：

```text
(x, y, z) -> (-x, y, z)
```

随后得到：

- 最大顶点误差：`5.0242958677880805e-15`；
- RMS 顶点误差：`3.972054645195637e-15`；
- 类型化边和面边界完全对应；
- OCCT `mirror(75)-76` 差体积：`0`；
- OCCT `76-mirror(75)` 差体积：`0`；
- 镜像后的实体通过 `checkshape`。

因此，连续实体和类型化 B-Rep 拓扑在反射后均重合。

## 当前算法为何拆分

当前 `find_rigid_transform` 有意构造右手坐标框架，只接受旋转加平移。这对应“零件能否在不翻面的情况下通过空间摆放重合”的严格制造等价定义。反射会改变手性，所以 75/76 在该定义下必须拆分。

## 后续处理建议

暂不改变严格分组结果。以后如需把左右手件归入同一几何族，可在严格实例组之外增加一层关系：

```text
geometry_family: [75, 76]
strict_groups: [75], [76]
relation: mirror_equivalent
mirror_plane: x = 0
```

若实施该功能，应添加独立回归测试，确保普通刚体同构、镜像同构和真正不同的零件不会互相混淆。
